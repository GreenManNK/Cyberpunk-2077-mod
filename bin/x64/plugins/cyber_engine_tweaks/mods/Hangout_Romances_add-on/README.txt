Hangout Romances add-on

This is a simple addon mod for: https://www.nexusmods.com/cyberpunk2077/mods/18972

Description:
------------
This addon allows the player to switch between top or bottom animation roles during
Hangout Romance scenes using a single hotkey. It uses the commands provided by the
original mod's author and does not include or modify any part of the original mod.
No credit is claimed for the base functionality.

Installation:
-------------
1. Extract the contents into your Cyberpunk 2077 `mods` folder:
   Cyberpunk 2077/bin/x64/plugins/cyber_engine_tweaks/mods/Hangout_Anim_Addon

2. Launch the game and press the assigned bindkey to toggle animation roles.
